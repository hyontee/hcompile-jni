BUILD FROM EXAGEAR

1. Put this project on the ExaGear filesystem.
2. Put ShadowHook files into:
   jni/shadowhook/include/shadowhook.h
   jni/shadowhook/prebuilt/armeabi-v7a/libshadowhook.so
3. Make sure the missing santrope-tea-gtasa/encryption sources are available beside jni if your source requires them.
4. Enter the directory containing jni and run:

   ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=jni/Android.mk NDK_APPLICATION_MK=jni/Application.mk V=1

If the terminal is already inside jni:

   ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=Android.mk NDK_APPLICATION_MK=Application.mk V=1

Output:
   libs/armeabi-v7a/libsamp.so

The ShadowHook .so is linked as a shared dependency and should also be packaged with the application.
